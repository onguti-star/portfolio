AutoDS — Automated Data Science Platform

A FastAPI + JS web app I built to automate the exploratory data analysis work that normally takes days. I ran it on my own 396K-row loan default dataset as a test: it independently surfaced the exact same charged-off rates by grade, term, and purpose that took me a full SQL + Python workflow to find manually — in under a minute. It's genuinely changed how I start every new dataset now; what used to be a day of EDA is a CSV upload and a coffee break.
